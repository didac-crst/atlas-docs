# Architecture Decision Records

ADRs capture durable decisions that shape the schema or security boundary.

| ADR | Title |
| --- | --- |
| [0001](0001-entity-external-reference.md) | Entity + ExternalReference replaces document_references |

## Format

Each ADR should state:

1. Status (accepted / superseded)
2. Context
3. Decision
4. Consequences

Milestone implementation plans that are no longer normative belong in
[archive/](../archive/) with a pointer to the ADR when one exists.
