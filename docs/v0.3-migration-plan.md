# AtlasDocs v0.3 Schema Migration Plan

Approved for implementation with the v0.3 milestone. Single Alembic revision
`0002_v03_entity_external_reference` (expand → backfill → constrain → drop).

## Target schema

### `entities`

| Column | Type | Notes |
| --- | --- | --- |
| `id` | UUID PK | Unchanged AtlasDocs identity |
| `entity_type` | VARCHAR(64) NOT NULL | `document` \| `concept` (others later) |
| `created_at` | TIMESTAMPTZ NOT NULL | Unchanged |

### `external_references` (new; replaces `document_references`)

| Column | Type | Notes |
| --- | --- | --- |
| `id` | UUID PK | New row id |
| `entity_id` | UUID NOT NULL UNIQUE FK → entities | One primary external binding per entity for v0.3 |
| `system` | VARCHAR(64) NOT NULL | e.g. `paperless` |
| `external_id` | VARCHAR(255) NOT NULL | String form of upstream id (`"184"`) |
| `created_at` | TIMESTAMPTZ NOT NULL | Copied from document_references when backfilled |

Constraints: `UNIQUE(system, external_id)`.

### `concepts` (subtype of entity)

| Column | Type | Notes |
| --- | --- | --- |
| `id` | UUID PK FK → entities.id | **Same UUID as the concept entity** |
| `ontology_id` | UUID NOT NULL FK | Unchanged |
| `code` / `name` | VARCHAR | Unchanged |
| `uq_concept_ontology_code` | | Unchanged |

### `relationship_types`

Existing columns kept. Add:

| Column | Type | Notes |
| --- | --- | --- |
| `directionality` | VARCHAR(32) NOT NULL | `directed` \| `symmetric`; default `directed` |
| `inverse_relationship_type_id` | UUID NULL FK → relationship_types.id | Optional inverse |

`target_ontology_id` remains for API target validation (classify into an ontology).

### `relationships`

| Column | Type | Notes |
| --- | --- | --- |
| `id` | UUID PK | Unchanged |
| `source_entity_id` | UUID FK → entities | Unchanged |
| `relationship_type_id` | UUID FK | Unchanged |
| `target_entity_id` | UUID NOT NULL FK → entities | **Replaces** `target_concept_id` |
| `origin` | VARCHAR(32) | Aligned vocabulary (below) |
| `status` | VARCHAR(32) | Unchanged |
| `created_at` | TIMESTAMPTZ | Unchanged |
| `created_by` | VARCHAR(255) NULL | Provenance |
| `model` | VARCHAR(255) NULL | Derived-knowledge metadata |
| `prompt_version` | VARCHAR(128) NULL | Derived-knowledge metadata |
| `generated_at` | TIMESTAMPTZ NULL | Derived-knowledge metadata |

Unique: `uq_relationship_triple` on
`(source_entity_id, relationship_type_id, target_entity_id)`.

Drop: `target_concept_id`, table `document_references`.

### Origin vocabulary

| Stored value | Notes |
| --- | --- |
| `manual` | Unchanged |
| `import` | Unchanged |
| `deterministic-rule` | Replaces stored `rule` |
| `llm` | Unchanged |
| `mcp` | New allowed value |

API compatibility: accept legacy `"rule"` on write; persist and return
`deterministic-rule`.

## Backfill steps (order)

1. **`entities.entity_type`**
   - Add nullable column.
   - Set `document` for every entity that has a `document_references` row.
   - Set `document` for any remaining entity with null type (defensive).
   - Make NOT NULL.

2. **Concept entities**
   - For each `concepts` row, `INSERT` into `entities (id, entity_type, created_at)`
     using the **existing `concepts.id`** as `entities.id`, type `concept`,
     `created_at = now()` (concepts had no timestamp).
   - Add FK `concepts.id → entities.id` (PK already matches).

3. **`external_references`**
   - Create table.
   - For each `document_references` row, insert:
     - new UUID `id`
     - same `entity_id`
     - `system = 'paperless'`
     - `external_id = CAST(paperless_document_id AS TEXT)`
     - same `created_at`
   - Assert row counts match.

4. **`relationship_types` metadata**
   - Add `directionality` default `'directed'`, backfill, set NOT NULL.
   - Add nullable `inverse_relationship_type_id` FK.

5. **`relationships` → entity targets + provenance**
   - Add nullable `target_entity_id`.
   - Backfill: `target_entity_id = target_concept_id` (concept UUID == entity UUID).
   - Assert no nulls; set NOT NULL; add FK + new unique constraint.
   - Drop old unique constraint and `target_concept_id`.
   - Add provenance columns (`created_by`, `model`, `prompt_version`, `generated_at`), all NULL.
   - Update `origin`: `rule` → `deterministic-rule`.

6. **Drop `document_references`.**

7. **Downgrade** (for Alembic completeness): reverse steps; recreate
   `document_references` from `external_references` where `system='paperless'`;
   restore `target_concept_id` from `target_entity_id` for concept-typed targets;
   map `deterministic-rule` → `rule`; drop new columns/tables.

## Application behavior (compatibility facade)

- Resolve Paperless id:
  `ExternalReference(system='paperless', external_id=str(id)) → Entity`.
- Create document entity: `Entity(type=document)` + Paperless external reference.
- Create relationship: resolve target concept entity by ontology/code/name;
  store `target_entity_id`; on types with `inverse_relationship_type_id`, also
  upsert the inverse edge; on `symmetric`, upsert the swapped edge with the
  same type.
- GET document responses: keep `paperless_document_id`; add optional
  `entity_id`; relationship `target` remains concept **name** for API compat;
  `origin` uses new vocabulary.

## Out of scope in this migration

Evidence tables, native notes, sidecars, LLM/MCP features, embeddings, graph UI,
product migration CLI, Supernova/Satlas deploy changes.
